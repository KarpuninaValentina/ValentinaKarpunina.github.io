# 📚 Karpunina's True Stories (Непридуманные истории Валентины Карпуниной)

Красивый и уютный сайт-визитка, созданный для публикации, бережного сохранения и чтения авторских рассказов моей бабушки о её детстве и реальной жизни.

🔗 **Ссылка на сайт:** https://karpuninavalentina.github.io/karpuninas-true-stories/

---

## ✨ Особенности проекта
*   **Литературный архив:** Удобная навигация и верстка для комфортного чтения текстов.
*   **Интерактивная кнопка «Сказать спасибо»:** Позволяет читателям отправлять мгновенную благодарность автору с защитой от накруток.
*   **Serverless-логика:** Кнопка работает через облачную функцию **Yandex Cloud Functions**.
*   **Совместная разработка:** Проект ведется через личный аккаунт в качестве соавтора (Collaborator), что избавляет от необходимости постоянно переключать профили.

---

## 🛠 Технологический стек
*   **Frontend:** HTML5, CSS3, JavaScript (отправка асинхронных запросов при клике).
*   **Backend:** Yandex Cloud Functions (бессерверная функция на Node.js для обработки нажатий).
*   **Хранилище данных:** Yandex Object Storage (бакет `counter-storage` с файлом `count.json` для хранения количества благодарностей).
*   **Хостинг:** GitHub Pages.

---

## 🧠 Как устроена кнопка «Сказать спасибо»

1.  **Клик:** Читатель нажимает на кнопку «Сказать спасибо» на сайте.
2.  **Запрос:** Сайт отправляет POST-запрос в специальную программу (функцию), которая работает в облаке Яндекса.
3.  **Сохранение:** Функция получает запрос, увеличивает счётчик на 1 и сохраняет новое число в облачном хранилище в бакете `counter-storage`.
4.  **Ответ:** Функция отправляет ответ обратно на сайт с новым числом.
5.  **Интерфейс:** Сайт обновляет счётчик на кнопке и меняет цвет сердечка на красный.

### 🛡️ Защита от накруток
Мы предусмотрели двухэтапную защиту, чтобы один человек не мог нажимать кнопку бесконечно:
*   **В браузере (Client-side):** При нажатии сайт запоминает это в `localStorage` пользователя. При следующем клике сайт видит отметку и блокирует повторный запрос.

## 🚀 Инструкция для соавтора: Как добавить новый рассказ

Чтобы добавить новое произведение, не нужно открывать сложные программы, всё делается прямо в браузере:
1. Откройте файл `index.html` в этом репозитории.
2. Нажмите кнопку `.` (точку) на клавиатуре для запуска встроенного веб-редактора GitHub.
3. Найдите структуру существующего блока с рассказом (теги `<article>` или `<div>`).
4. Скопируйте этот блок, вставьте ниже и замените текст на новый рассказ бабушки.
5. Нажмите **Commit changes** (Сохранить изменения) на панели слева. Через 1-2 минуты GitHub Pages сам обновит сайт.

## 📌 Что делать, если кнопка «Спасибо» не работает
Если читатели сообщают о проблемах со счётчиком:
1. Попросите пользователя очистить кэш браузера и обновить страницу.
2. Проверьте логи функции в консоли Yandex Cloud — там видно, приходят ли запросы и есть ли ошибки.
3. Убедитесь, что бакет `counter-storage` в Яндексе остаётся публичным на чтение.
